# Tiến Lên Đại Chiến

Trò chơi bài **Tiến Lên Miền Nam** đơn giản chạy trực tiếp trên trình duyệt (HTML/CSS/JavaScript thuần).

## Cách chơi

1. Mở file `index.html` bằng trình duyệt.
2. Bạn chơi với 3 máy.
3. Chọn lá bài cần đánh rồi nhấn **Đánh bài**.
4. Có thể **Bỏ lượt** khi đã có bài trên bàn.
5. Ai hết bài trước sẽ thắng.

## Luật hiện đang hỗ trợ

- Đánh **rác** (1 lá), **đôi** (2 lá cùng số), **sám cô** (3 lá cùng số).
- Cùng kiểu bài mới được đè và phải lớn hơn bài trước.
- Người có `3♠` đi đầu; lượt mở đầu phải chứa `3♠`.

> Đây là phiên bản rút gọn để dễ chơi nhanh; chưa bao gồm sảnh, tứ quý/chặt heo, đôi thông.
